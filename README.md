# WebForAILove

## 海克斯乱斗组合参考

用浏览器打开 `hextech-aram/index.html`（双击或把文件拖进浏览器即可，不需要服务器）。

进游戏前用简称搜索。`ys`、`亚索`、`yasuo`、`jfjh` 都能找到亚索；简称撞车时先点英雄，点之前能看到该英雄整体胜率是否超过 50%。点中英雄后可以在「海克斯」和「装备」之间切换。海克斯默认是有胜率的前 10，按胜率从高到低，每条写场次和相对未选取的百分点，不足 100 场会标出来。也可以改成按相对未选取或场次排序，并按棱彩、黄金、白银或至少 100 场筛选。相对未选取来自 Mayhem:Meta，页面不计算 Hexdata 的 HexScore，也不估算海斗分。装备也是海克斯大乱斗：出门装、鞋子、核心各按 arammayhem.com 登场率从高到低最多列 3 套，登场率相同再看胜率，并标明第几套。能对上的装备用 Data Dragon 16.21.1 的图标，旁边留短名字；对不上的标成缺图。页面数据日期 2026-11-03。加点分开写 arammayhem.com 和 OP.GG，不合成一套。Mayhem:Meta 没有购买顺序，所以装备不从那边取。全部英雄的超过 / 未超过 50% 在 `hextech-aram/champions.html`。海克斯和胜率分组来自 2026-10-25 抓取的 Mayhem:Meta 补丁 26.21。这一版胜率只统计嚎哭深渊：官方说明里屠夫之桥和 Koeshin's Crossing 本补丁不在海克斯乱斗队列。不是国服。
