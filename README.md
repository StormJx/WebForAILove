# WebForAILove

## 海克斯乱斗组合参考

用浏览器打开 `hextech-aram/index.html`（双击或把文件拖进浏览器即可，不需要服务器）。

进游戏前用简称搜索。`ys`、`亚索`、`yasuo`、`jfjh` 都能找到亚索；简称撞车时先点英雄，点之前能看到该英雄整体胜率是否超过 50%。点中英雄后可以在「海克斯」和「装备」之间切换。海克斯是海克斯乱斗里有胜率的前 10，按胜率从高到低。装备也是海克斯大乱斗：出门装、鞋子、核心各按 arammayhem.com 登场率从高到低最多列 3 套，登场率相同再看胜率，并标明第几套。能对上的装备用 Data Dragon 16.21.1 的图标，旁边留短名字；对不上的标成缺图。页面数据日期 2026-10-29。Mayhem:Meta 没有购买顺序，所以装备不从那边取。全部英雄的超过 / 未超过 50% 在 `hextech-aram/champions.html`。海克斯和胜率分组来自 2026-10-25 抓取的 Mayhem:Meta 补丁 26.21。这一版胜率只统计嚎哭深渊：官方说明里屠夫之桥和 Koeshin's Crossing 本补丁不在海克斯乱斗队列。不是国服。
