# WebForAILove

## 海克斯乱斗组合参考

用浏览器打开 `hextech-aram/index.html`（双击或把文件拖进浏览器即可，不需要服务器）。

进游戏前用简称搜索。`ys`、`亚索`、`yasuo`、`jfjh` 都能找到亚索；简称撞车时先点英雄，点之前能看到该英雄整体胜率是否超过 50%。点中英雄后可以在「海克斯」和「装备」之间切换。海克斯是海克斯乱斗里有胜率的前 10，按胜率从高到低。装备每个英雄只有一套，顺序来自 Blitz.gg 的普通极地大乱斗 Build Order，页面写明不是海克斯乱斗。全部英雄的超过 / 未超过 50% 在 `hextech-aram/champions.html`。海克斯和胜率分组来自 2026-10-25 抓取的 Mayhem:Meta 补丁 26.21。这一版来源只统计嚎哭深渊：官方说明里屠夫之桥和 Koeshin's Crossing 本补丁不在海克斯乱斗队列。不是国服。
