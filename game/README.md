# 芦岸戍卫

一个原创的小型塔防，给 Godot 4.7.2 标准版（不是 .NET / Mono）。四关，每关一条水路、三种塔、每座塔两条升级路线、五波敌人、一位巡岸卫。画面是引擎里画的纯色几何，没有外部付费素材。

界面字体是 [Noto Sans CJK](https://github.com/notofonts/noto-cjk) 的子集，已改名为 Reedbank Sans，授权见 `fonts/OFL.txt`（SIL Open Font License 1.1）。

## 在 Mac 上打开

1. 打开已经装好的 `/Applications/Godot.app`（Godot **4.7.2** 标准版）。
2. 导入本目录的 `project.godot`（仓库里的 `game` 文件夹）。
3. 等导入结束，按编辑器右上角的播放（或 F5）。
4. 游戏从**选关**开始。第 1 关「旧渠水闸」默认能进，守住以后才解锁下一关。四关可以一局接一局打完，打完点「回到选关」。
5. 进关之后用鼠标：
   - 「开始守闸」
   - 点地图上的圆垫，再点底部的石弩、霜坛或焰壶
   - 选中塔之后，在底部选一条升级路线（一座塔只能走一条，各两级）
   - 点渠边空地，巡岸卫会走过去；「断流」是他的范围技能
   - 「出波」放出下一波，一共五波
6. 五波清完并且生命还在，就是赢，并写入通关、打开下一关。生命到 0 就是输。

桌面快捷键：`1` `2` `3` 造塔，`Q` `E` 升级，`R` 出售，`F` 断流，空格出波。

生命和金币只在这一局里变化。「保存」「读取」写的是研究所购买和各关有没有通关，不会把本局生命或金币存进去。存档在 Godot 的 `user://reedbank_save.json`。

关卡列表在 `data/levels.json`。每一关的水路和波次在 `data/` 里单独一份 JSON，不写死在某一个脚本中。

## 以后装到 iPhone 16

这一步还没有装到手机上。需要你自己的 Mac、与 4.7.2 匹配的 iOS 导出模板，以及你已经装好的 Xcode 和签名。

1. 在 Godot 里打开 **编辑器 → 管理导出模板**，下载 **4.7.2** 的标准导出模板（不要下 .NET / Mono 那一份）。
2. **项目 → 导出**，选预设 **iOS**。套装标识符目前是占位的 `com.reedbank.garrison`，可以改成你自己的。
3. 填写你的 **App Store Team ID**（10 位。Xcode 里 Signing 显示的名字不能直接拿来填）。不填的话导出会报错。
4. 预设里已经打开 **仅导出工程**（Export Project Only），并限制为 iPhone、横屏。导出到一个**空文件夹**，得到 Xcode 工程，而不是已经签过名的 ipa。
5. 用现有的 Xcode 打开那个 `.xcodeproj`，选中你的 iPhone 16，签好名再运行。

游戏按横屏排。底部两排按钮放在拇指区；刘海 / 灵动岛和底部横条会按系统安全区再留出空白。桌面窗口拉大时用的是同一套界面。
